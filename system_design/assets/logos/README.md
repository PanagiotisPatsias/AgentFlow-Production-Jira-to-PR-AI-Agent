# Diagram brand assets

These SVG brand marks identify the technologies used by AgentFlow. They are not an AgentFlow logo or a statement of sponsorship. Colours and proportions of the original multi-colour assets are preserved; Simple Icons supplies brand-colour monochrome marks for the remaining technologies.

[`sources.json`](sources.json) records each asset's upstream download and, where available, its official brand source. Assets are vendored so the rendered diagrams work offline and in GitHub README image rendering. The renderer embeds vector paths and namespaces internal gradient IDs; it does not link to external images, use emoji or generate substitute logos.
